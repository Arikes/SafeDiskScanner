# 应用磁盘占用统计

按本轮用户请求实现，沿用 Tkinter/ttk，在“磁盘清理”页展示应用名称、App 包、已识别外部数据、已确认合计和状态，下方列出路径、大小与关联依据。快速检索页继续留空。

应用发现采用常见安装目录递归枚举，加 Spotlight 索引补充；校验现存 .app，去除重复路径和包内辅助应用。范围包含当前用户及系统常见应用，非 .app 命令行工具、自定义未索引位置不保证覆盖。

外部数据先按 Bundle ID、签名中的 App Group 标识匹配标准 Library 位置；软件名匹配仅列为疑似，不计已确认合计。一个位置关联多个应用时标为共享，单独显示，不重复加入每个应用合计。统计当前用户和 /Library，其他用户及自定义资源目录不保证覆盖。无读取权限显示异常与不完整状态。

大小采用文件已分配块数估算，内部符号链接不跟随，硬链接在单次目录测量中去重；APFS 克隆、快照等使该值不等于可释放空间。关联父子目录去重。

所有枚举、签名读取、大小计算在后台，最多两个并行任务，队列向 UI 逐步交付；支持取消、刷新与名称/标识搜索、按大小排序。首次进入页面自动发现应用并开始统计。仅查看，不增加清理或卸载动作。

备选：全盘逐文件归属无法可靠确定且代价高；仅按名称匹配误报高。本版采用标识匹配加可查看的疑似目录，覆盖和可信程度均明确展示。
