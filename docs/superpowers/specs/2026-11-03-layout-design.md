# 大文件扫描器布局优化

目标：功能不变，提高信息层次、列表可用空间和窗口缩小时的可用性。

采用现有 Tkinter/ttk：顶部标题和外观切换，下方三项磁盘概览；左侧目录导航和快捷入口，右侧上方文件浏览，下方扫描设置及结果。右侧上下区域、左右区域可拖动分隔条调整大小。扫描状态单独成行，路径输入随窗口伸缩，长列表提供水平滚动。

方案比较：只调整间距无法解决顶部拥挤；标签页会隐藏扫描结果与目录的同时查看能力；采用分区布局，保留同时查看能力。此选择由实现者按现有用途确定。

保留全部事件绑定、扫描算法、线程、缓存、隐藏文件、访达操作、深浅色切换。无新增依赖。仅修改控件布局、样式及磁盘数值展示。验证默认/较小窗口、两种外观、文件导航、扫描结果和取消按钮，并重新生成 arm64 应用及 pkg。
