# 桌面界面视觉整理

用户确认保留 Tkinter/ttk，采用简洁、扁平的 macOS 工具风格。维持文件浏览和大文件扫描双标签页、全部扫描/排序/筛选/删除及持久化行为。

浅色使用浅灰工作区、白色内容区和蓝色强调色；深色提供对应背景、边框与文字色。统一系统字体、控件高度、8/12/16/20 间距。压缩顶部容量概览，增加列表可用面积。侧栏独立底色，目录文字使用中性色。表格去立体边框，细分隔线、清晰选中态。标签页采用扁平背景和底部指示线。按钮区分主要、次要、轻量操作；复选框和滚动条采用统一扁平样式。筛选浮层沿用现有交互并统一样式。为空列表增加说明。

采用 ttk 样式和少量 Tk PhotoImage 控件元素，无第三方界面依赖；不增加复杂动画或整套自绘控件。相较只改配色，统一控件元素能解决默认主题的立体边框问题，同时保留 ttk 的键盘操作与状态管理。

验证：现有 42 项测试；核心业务方法 AST 对比；实际浅色/深色、双标签页、筛选浮层及小窗口检查；构建 arm64 应用和安装到 /Applications 的 pkg。
