# 布局优化实施计划

**Goal:** 保留功能，重排 Tkinter 界面并交付新版安装包。
**Architecture:** 单文件保持不变，只修改初始化布局、主题样式和磁盘展示变量。
**Tech Stack:** Python、Tkinter/ttk、PyInstaller、pkgbuild。
**Spec:** ../specs/2026-11-03-layout-design.md

## 约束与检查重点

- 扫描、取消、目录导航、隐藏文件与访达操作逻辑保持不变。
- 缩小窗口仍可使用全部按钮；长路径和状态不能挤压其他控件。
- 两种外观均要检查输入框、禁用按钮、表头和正文对比度。
- 可调整列表区域比例，支持长路径水平滚动。
- 安装包必须包含与验证应用一致的完整文件。
