# 应用磁盘占用 Implementation Plan

> 执行方式：当前会话直接实现，保留已有两个新标签页改动，不自动提交。

**Goal:** 在磁盘清理页列出应用本体及已识别外部数据占用。

**Architecture:** `app_storage/` 功能包分离数据模型、应用发现、外部数据关联、大小测量、后台服务、显示转换和页面；主程序仅接入该页面。

**Tech Stack:** Python 标准库、Tkinter/ttk、macOS mdfind/codesign。

**Spec:** `docs/superpowers/specs/2026-11-03-app-storage-design.md`

## Global Constraints

- 保留现有文件浏览、扫描、全选、筛选、深浅色和快速检索占位页行为。
- 共享和疑似路径不加入单应用已确认合计；无权限不是 0。
- 后台不得调用 Tk；无删除、安装、网络请求。

## Review Focus

- 多份同 ID 应用、共享容器及父子路径避免重复计入。
- 损坏 plist、索引无结果、权限异常仍返回其余应用和明确警告。
- 取消后可重新扫描，旧结果不可污染新一轮。
- 符号链接循环、硬链接、已删除文件及大目录不阻塞取消。
- 窄窗口下四个标签和换肤按钮不重叠；未扫描不能显示为 0。
